# SISTEMA-DE-GESTION-ACADEMICA-FASE3
Sistema de Gestión Académica en C++ utilizando listas enlazadas simples para estudiantes, asignaturas y notas. Entrega Fase 3.
---

## Herramientas de Apoyo y Asistencia

Este proyecto fue desarrollado con el apoyo y orientación de **Gemini (Google AI)** como asistente colaborativo de programación para:
* Refactorización y optimización de código bajo principios de *Clean Code*.
* Verificación de la estructura de datos dinámica de listas enlazadas simples en C++.
* Guía en el manejo manual de memoria dinámica (`new`, `delete` y punteros) alineado con la metodología de la asignatura.
